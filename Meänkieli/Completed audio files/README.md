# Completed audio files

These 40 MP3/WAV recordings are preserved as supplied. Use the smaller recordings in [Audio files for android app](../Audio%20files%20for%20android%20app/README.md) for everyday app practice. The numerical names in Del 1 and Del 2, and the case names in Del 3, correspond to the recording groups, but versions and processing differences have not been checked by listening to every pair.

| Folder | Files | Description |
| --- | ---: | --- |
| [Del 1](Del%201/README.md) | 20 | convo 1–20, MP3 and WAV |
| [Del 2](Del%202/README.md) | 15 | Konv1–Konv15 processed WAV |
| [Del 3](Del%203/README.md) | 5 | Processed WAV named for five cases |

Treat these originals as stable media. Repeatedly replacing large binaries adds full versions to Git history. See [media storage notes](../../docs/MEDIA.md).
