# Completed audio files

These  recordings are the same audio as the files intended for use with the android app, but they have been edited as standalone audio files. The proceed with a Swedish utterance, a period of silence allowing the user to speak the Meänkieli, then the Meänkieli translation spoken twice with a period of silence between each, allowing the user to practice speaking each utterance three times. This is an earlier version of the work on which development has stopped in favor of developing audio for the android app implementation. These are useful for when hands-free practice is necessary.
