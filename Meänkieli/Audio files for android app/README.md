# Study recordings for the audio players

Choose a set, read its source text, then open a recording in the [web player](../Apps/Audio_player_web_version.html) or the Android dialogue trainer. The original folder names and recording filenames are preserved, including spaces and diacritics.

| Folder | Recordings | Source |
| --- | ---: | --- |
| [set 1](set%201/README.md) | 20 | Everyday dialogues in the course material |
| [set 2](set%202/README.md) | 15 | Konversation 1–15 in the course material |
| [set 3](set%203/README.md) | 10 | Owner-supplied replacement extended-dialogue document |
| [grammatik/böjning](grammatik/b%C3%B6jning/README.md) | 12 | Case examples and conversations in the course material |
| [grammatik/prepositioner](grammatik/prepositioner/README.md) | 11 | Prepositioner.docx |
| [grammatik/dåtid](grammatik/d%C3%A5tid/README.md) | 15 | Perfect/imperfect sentence tables for seven verb types |

The archive contains document text rather than Google Drive shortcut placeholders. Every study folder displays its relevant source text and links to the preserved Word document. Filename and heading matches establish the mappings; individual recordings have not all been transcribed or checked line by line.

The set 1 greeting has an `.mp4` extension; browser/device support for that particular file has not been tested. If a player cannot decode a format, use a compatible local audio player. Originals have not been transcoded.
