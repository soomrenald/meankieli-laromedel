### Hej

| Meänkieli | Svenska |
| --- | --- |
| Hei, kunkas sie jaksat? | Hej, hur mår du? |

| Hei, mitääs kuuluu? | Hej, nåt nytt? |
| Ei mithään, mie olen vasta tullu kotia | Inget, jag har precis kommit hem. |

| --- | --- |

### Hemma

| Meänkieli | Svenska |
| --- | --- |
| Mie häyn olla kotona tänä päivänä, mie häyn korjata köökin ja nukkuma huohnet. | Jag måste vara hemma idag, jag måste städa köket och sovrummen. |
| Ja sitten mie häyn kastela kukkat sisälä ja ulkona. | Och sen måste jag vattna blommorna inne och ute. |
| Oota vähän, se sattaa ja on kova tuuli. | Vänta lite, det regnar och blåser hårt. |
| Saattasimma jua kaffia sillaikaa. | Vi skulle kunna dricka kaffe under tiden. |

**Source note / text without a separate translation:**

> (sillaikaa kommer från sillä aikaa)

| Meänkieli | Svenska |
| --- | --- |
| Hän häätyy ottaa matoot ulos ja kuurata laatian. | Han/hon måste ta ut mattorna och skura golvet. |
| Mie häyn pestä matoot ensinä. | Jag måste tvätta mattorna först. |

### Stiga upp/Frukost

| Meänkieli | Svenska |
| --- | --- |
| Koskas sie nouset ylös? | När stiger du upp? |
| Minkäs aikana sie nouset? | Vilken tid stiger du upp? |
| Mie nousen seitemän aikana. | Jag stiger upp klockan 7. |
| Mitäs sie syöt fruukostiksi? | Vad äter du till frukost? |
| Mie halvan voi-leivän. | Jag vill ha smörgås. |
| Halvattakos munia/munnaa? | Vill ni ha ägg? |
| Jos mie söysin puuroa tänä aamuna… | Om jag skulle äta gröt idag…. |
| Halvaks kaffia eli teetä fruukostin kanssa? | Vill du ha kaffe eller te med din frukost? |

### Jobb

| Meänkieli | Svenska |
| --- | --- |
| Lähetkos töyhiin nyt? | Går du till jobbet nu? |
| Koskas sie tuleet kotia? | När kommer du hem? |
| En mie tiä, mie meinasin käyä marsimassa kaupungila ennenko mie tuleen kotia. | Jag vet inte, jag tänkte gå på stan innan jag<br>kommer hem. |
| Se näyttää ette mie häyn olla töissä yli pyhään. | Det ser ut som att jag måste jobba över helgen. |
| Meillä on paljon tekemistä nyt justhiins. | Vi har mycket att göra just nu. |

### Sova

| Meänkieli | Svenska |
| --- | --- |
| Mie nukuun vähään enämpi. | Jag sover lite längre |
| Ei, nouse ylös nyt! | Nej, stig upp nu! |
| Missäs minun vatheet on? | Var är mina kläder? |

### Ringa

| Meänkieli | Svenska |
| --- | --- |
| Soita sitte ko sie oleet framila! | Ring sen när du är framme! |
| Soita ko sie tuleet framile! | Ring när du har kommit fram! |
| Mie tuleen kotia hiljain. | Jag kommer hem sent. |
| Minkas aikana? | Vilken tid? |
| En ole kotona ennenko yhentoista aikana. | Jag är inte hemma förrän klockan 11. |
| Se on liika hiljasta, mie soitan sulle huomena. | Det är för sent, jag ringer dig i morgon.. |

### Pengar

| Meänkieli | Svenska |
| --- | --- |
| Mitä(s) se maksaa? | Vad kostar den/det? |
| Kunkas paljon se maksaa? | Hur mycket kostar den/det? |
| Se on liika tyris. | Den är för dyr/det är för dyrt |
| Se on varhmanki halvempi mualla. | Den är säkert billigare någon annanstans |

| Ei en mie tartte rahaa. | Nej jag behöver inte pengar. |
| Ota sen kuitenki. | Ta dom i alla fall. |

| Mulla on vanhoita kaveria Suomessa. | Jag har gamla kompisar i Finland |
| Se kuulutta somalta, mie asun Korpilombolon likelä (eller lähelä). | Det låter trevligt, jag bor nära Korpilombolo. |
| Mitäs sie meinat tehjä täällää? | Vad tänker du göra här? |
| En ole vain päättäny mithään vielä muutten ko käyä perheen tykönä. | Jag har inte bestämt något än förutom att hälsa på familjen. |

### Skidor/skridskor

### Plocka bär

| Meänkieli | Svenska |
| --- | --- |
| Mie tykkään paremin kesästä sentänko mie tykkän plockata mustikoita ja muita marjoja. | Jag gillar sommaren bättre därför att jag gillar att plocka blåbär och andra bär. |
| Mutta se ei ole hauska plockata hilloja, net on liika/liian märät. | Men det är inte kul att plocka hjortron, dom är för blöta. |

**Source note / text without a separate translation:**

> (Märät kommer från märkä=wet)

| Mutta net on niin makeat, olletikki kahvijuuston kanssa. | Men dom är goda, speciellt med kaffeost. |
