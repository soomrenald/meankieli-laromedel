# Meänkieli materials

The original archive's meaningful folders and filenames are preserved. Start with the [repository guide](../README.md), the [app guide](Apps/README.md), or [recordings and dialogue text](Audio%20files%20for%20android%20app/README.md).

- [Apps](Apps/README.md): browser player and documentation of the Android packages.
- [Audio files for android app](Audio%20files%20for%20android%20app/README.md): smaller study recordings and complete relevant source text in every study folder.
- [Completed audio files](Completed%20audio%20files/README.md): original MP3/WAV recordings.
- [Docs](Docs/README.md): preserved Word originals, Markdown readings, and owner-created vocabulary workbooks.
- [Archive](Archive/README.md): earlier packages and the replaced Set 3 document.

The original [keyboard wordlist ZIP](dictionary%20for%20chrome.zip) is available; see its actual format and usage limits in the [app guide](Apps/README.md#keyboard-wordlist-archive).
